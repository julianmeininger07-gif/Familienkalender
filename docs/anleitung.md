# Kurzanleitung für alle

## 1. Einladung annehmen

Du bekommst vom Admin einen Link (z. B. per WhatsApp). Öffne ihn, gib deine E-Mail-Adresse und ein
Passwort ein. Fertig. Der Link funktioniert nur einmal.

## 2. Als App aufs Handy legen

**iPhone:** Link in **Safari** öffnen → unten auf **Teilen** (Viereck mit Pfeil) → **Zum Home-Bildschirm**.
Danach den Kalender immer über das neue gelbe Symbol öffnen.

**Android:** Link in **Chrome** öffnen → Menü **⋮** → **App installieren** (oder „Zum Startbildschirm
hinzufügen“).

Am Computer reicht der Browser. In Chrome und Edge kann man ihn über das Symbol rechts in der
Adressleiste auch als App installieren.

## 3. Benachrichtigungen einschalten

In der App auf **Einstellungen** → **Benachrichtigungen einschalten** → im Dialog **Erlauben**. Mit
**Test-Nachricht** prüfst du, ob es klappt. Das muss auf jedem Gerät einzeln gemacht werden.

Du bekommst eine Nachricht, wenn

- dich jemand zu einem Termin einlädt,
- jemand auf deine Einladung zu- oder absagt,
- eine Erinnerung fällig ist, die du bei einem Termin eingestellt hast.

## 4. Termine

- **Neuer Termin:** auf **+** tippen oder im Kalender auf einen Tag. Pflicht sind nur Beschreibung, Datum
  und Uhrzeit. Ort, Erinnerung, Notizen und Kategorie stehen unter „+ Ort, Kategorie …“.
- **Privat:** Private Termine sehen nur du und die Eingeladenen. Für alle anderen sind sie unsichtbar.
- **Einladen:** Personen ankreuzen. Mit „Zu-/Absage erforderlich“ wird die Person um eine Antwort gebeten.
  Offene Einladungen stehen unter **Einladungen**.
- **Wiederholen:** Häkchen bei „Wiederholen“, dann täglich, wöchentlich, monatlich oder jährlich. Beim
  Ändern oder Löschen fragt die App, ob nur dieser Termin oder die ganze Serie gemeint ist.

## 5. Was im Kalender zu sehen ist

- **Gelb** = Schulferien in Bayern
- **Rot** = gesetzlicher Feiertag in Bayern
- Jede Person hat eine eigene Farbe. Über **Filter** blendest du Personen und Kategorien ein oder aus.
